# Little Moments visual system

Cream paper and burgundy form the foundation. Pink, sage, lavender, and cork add material-specific accents. The physical booth leads the welcome screen; task screens prioritize tools and a shared live paper preview. The memory board uses layered keepsakes, pins, and a wooden frame.

Tokens: paper `#faf3e8`, vintage red `#8b3f43`, dusty pink `#e8a5b5`, sage `#dce8d2`, cork `#b78c63`, dark ink `#292522`. Interface ink is `#493b34` and secondary text `#796b60`.

Typography: DM Serif Display for headings, Nunito for controls and explanatory copy, Caveat for captions and handwritten details. Headings use 31–48px, body 11–13px in the intentionally compact booth UI, handwritten annotations 18–28px.

Controls use 6px corners, tactile paper surfaces, modest offset blurred shadows, visible focus rings, and clear selected states. Motion is concentrated on curtain opening, strip printing, pinning, and detail unfolding. Reduced-motion preferences remove animation. Mobile stacks tools and preview, uses a two-column template selector, and keeps the physical booth centered.
